Primary Checkout Drop-off Reasons

Categorization of 10,098 checkout drop-offs

1. ETA Delay (>40m): 3,193 sessions (31.62%)
2. Fee Surcharges (Delivery + Service): 2,595 sessions (25.70%)
3. Price Comparison / Hesitation: 1,907 sessions (18.88%)
4. Payment Gateway Timeouts: 1,873 sessions (18.55%)
5. Promo Restriction Barrier: 530 sessions (5.25%)

1. Late Fee Disclosure

Delivery and convenience fees are not displayed during menu browsing. When added at the final screen, orders under ₹250 face fees representing 20% to 35% of total food cost, triggering drop-off.

2. ETA Inflation at Checkout

Menu cards often display 25–30 minute estimates. When real-time courier dispatch re-estimates to 50+ minutes at checkout, 85.8% of users abandon the transaction.

3. Payment Gateway Timeouts

18.6% of lost users attempted payment but experienced UPI app-switch timeouts or OTP validation failures, representing involuntary loss of high-intent orders.

Production SQL Query Library

Standard ANSI SQL compatible with PostgreSQL, DuckDB, Snowflake, BigQuery, and SQLite

-- Query 01: Overall Funnel Conversion & Drop-off Calculation
WITH session_stages AS (
    SELECT 
        s.session_id,
        1 AS reached_app_open,
        MAX(CASE WHEN e.event_name IN ('view_restaurant', 'view_item') THEN 1 ELSE 0 END) AS reached_discovery,
        MAX(CASE WHEN e.event_name IN ('add_to_cart', 'view_cart') THEN 1 ELSE 0 END) AS reached_add_to_cart,
        MAX(CASE WHEN e.event_name = 'initiate_checkout' THEN 1 ELSE 0 END) AS reached_checkout,
        MAX(CASE WHEN e.event_name = 'order_success' THEN 1 ELSE 0 END) AS reached_order_success
    FROM sessions s
    LEFT JOIN events e ON s.session_id = e.session_id
    GROUP BY s.session_id
)
SELECT 
    COUNT(session_id) AS total_sessions,
    SUM(reached_discovery) AS discovery_sessions,
    SUM(reached_add_to_cart) AS cart_sessions,
    SUM(reached_checkout) AS checkout_sessions,
    SUM(reached_order_success) AS orders_placed,
    ROUND(100.0 * SUM(reached_order_success) / COUNT(session_id), 2) AS end_to_end_conversion_pct,
    ROUND(100.0 * (1.0 - SUM(reached_order_success) * 1.0 / NULLIF(SUM(reached_checkout), 0)), 2) AS checkout_abandonment_pct
FROM session_stages;

Power BI DAX & Tableau Formulas

Calculated measures for BI implementations

// DAX Measure: Checkout Drop-off Rate (%)
Checkout Dropoff Rate Pct = 
VAR CheckoutSessions = 
    CALCULATE(
        DISTINCTCOUNT(fact_sessions[session_id]), 
        fact_sessions[max_funnel_stage] IN {"4_checkout", "5_order_success"}
    )
VAR SuccessfulOrders = 
    CALCULATE(
        DISTINCTCOUNT(fact_sessions[session_id]), 
        fact_sessions[max_funnel_stage] = "5_order_success"
    )
RETURN
    (1 - DIVIDE(SuccessfulOrders, CheckoutSessions, 0)) * 100

// DAX Measure: 30-Day Repeat Order Rate (%)
Repeat Order Rate 30D = 
VAR TotalBuyers = DISTINCTCOUNT(fact_orders[user_id])
VAR RepeatBuyers = 
    CALCULATE(
        DISTINCTCOUNT(fact_orders[user_id]), 
        fact_orders[order_sequence_number] >= 2
    )
RETURN
    DIVIDE(RepeatBuyers, TotalBuyers, 0) * 100
